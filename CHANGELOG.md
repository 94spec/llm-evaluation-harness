# Changelog

All notable changes to this evaluation framework are documented here.

## [1.0.0] — 2026-07-29

- Added an architecture diagram and compact evidence index for the evaluation lifecycle.
- Stabilized four task-family adapters, schema validation and typed error ledgers.
- Documented the agreement denominator, deal-cluster confidence intervals and release-gate path.
- Published the dependency-free CLI and CI-tested synthetic evaluation workflow as the stable release surface.

## [0.1.0] — 2026-07-28

- Added evaluation for QA scorecards, deal summaries, semantic analytics and violation flags.
- Added schema validation, expert-agreement metrics and deal-cluster bootstrap confidence intervals.
- Added typed error ledgers, immutable run manifests and cost/latency reporting.
- Added absolute and baseline-relative regression gates.
- Added deterministic synthetic fixtures and thirteen tests.
- Added Python 3.11/3.12 CI with passing- and failing-gate smoke tests.
